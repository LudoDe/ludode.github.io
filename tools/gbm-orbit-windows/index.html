GBM orbital subtraction · browser component

Orbit-window calculator.

Enter a Fermi Mission Elapsed Time and a source interval. The calculator returns the matching background windows at the requested number of spacecraft orbits before and after the source.

Inputs

Fermi Mission Elapsed Time, in seconds.

The OSV v1.3 default. Replace it with a recalculated period when available.

Positive integers separated by commas, for example 14, 16, 30.

Calculated intervals

Source and orbit-shifted Fermi MET intervals
RegionStart METStop METShift (s)

Scope: this reproduces the deterministic interval calculation in the desktop tool’s Regions class. It does not download FITS files, test data quality or perform the background subtraction itself. All calculation happens on this page.

Part of the GBM Orbital Subtraction Viewer.
