    How it works

    The desktop calculation, moved into a private browser workspace.

    1. Good PHAII rows are combined per detector and interpolated onto the native CTIME or CSPEC cadence.
    2. The selected pre- and post-orbit regions are averaged into the background estimate.
    3. You get an interactive detector preview plus source/background FITS, CSV, NPZ and run metadata in one ZIP.

    This browser release ports the core PHAII subtraction and export flow. Detector-angle and occultation diagnostics remain available in the desktop application.
